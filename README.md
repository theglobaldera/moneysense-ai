# MoneySense AI

**Make money make sense.**

An AI-powered financial literacy assistant for young people (16–25), particularly young
Nigerians managing money independently for the first time. Built for AI BuildFest 2026.

MoneySense AI is a financial **education** platform, not a financial advice, banking, or
investment platform. It helps people understand everyday money concepts and decisions — it
never tells them what to specifically do with their own money.

## The golden path (demo journey)

```
Question → Explanation → Scenario → Calculation → Quiz → Learning
```

1. **Ask** a question ("What is compound interest?") → get a structured explanation.
2. **Explore** a real-life **Scenario** ("Should I take this loan?").
3. **Simulate** the exact numbers in the Savings/Loan calculator.
4. **Learn** — take a short quiz and get feedback.
5. **Progress** — see what you've learned, stored locally on your device.

## Beyond the four examples: describe your own situation

The Scenarios page isn't limited to the 4 worked examples. A **"Describe Your Own Situation"**
box lets a user type their real financial situation in free text and get back an AI-generated,
structured read (Situation Recap → Key Considerations → Questions Worth Asking → Suggested Next
Step) — same disciplined, non-prescriptive structure as Ask MoneySense, powered by the same
Gemini backend (`app/api/scenario/route.ts`, `lib/ai/scenarioSystemPrompt.ts`). The 4 hand-written
examples remain as a reliable fallback if AI is ever unavailable.

## Tech stack & why

| Layer | Choice | Why |
|---|---|---|
| Framework | Next.js 14 (App Router, TypeScript) | Pages + server API routes in one project; deploys to Vercel free tier with zero config. |
| Styling | Tailwind CSS | Fast, consistent, mobile-first responsive styling without a component library dependency. |
| AI | Google Gemini API (`gemini-flash-latest`, a self-updating alias), called server-side only (`app/api/ask/route.ts`, `app/api/scenario/route.ts`, shared via `lib/ai/gemini.ts`) | Free tier — no credit card required (1,500 requests/day). Keeps the API key off the client. Used for Ask MoneySense and the custom-scenario feature — explanations, examples, conversation, never arithmetic. |
| Calculations | Plain TypeScript functions (`lib/finance.ts`) | Savings and loan math is never generated by AI — it's deterministic code, so numbers are always correct and reproducible. |
| Content (Scenarios & Quizzes) | Hand-written data (`lib/content/`) | No AI dependency for the core demo path, so it never breaks on a network or model issue. |
| Progress tracking | Browser `localStorage` (`lib/progress.ts`) | No accounts, no backend, no personal data collected — matches the MVP scope decision. |
| Icons | lucide-react | Lightweight, no extra design system needed. |
| Motion | Framer Motion | Scroll reveals, hover/tap feedback, and state-transition animations throughout — the difference between a "coded demo" feel and a real product feel. |

**AI's role, by design:** AI explains, converses, and teaches. Code calculates. The Ask
MoneySense system prompt (`lib/ai/systemPrompt.ts`) enforces this — it explicitly avoids
performing precise arithmetic and instead points users to the Simulator.

## Project structure

```
app/
  page.tsx              Home
  ask/                  Ask MoneySense (AI chat)
  api/ask/route.ts       Server-side AI endpoint for Ask MoneySense (keeps GEMINI_API_KEY private)
  api/scenario/route.ts  Server-side AI endpoint for the custom-scenario feature
  scenarios/             Scenario list (4 examples + custom submission) + situation → choice → outcome flow
  simulate/              Savings & Loan calculators (Daily/Weekly/Monthly/Annually, real formulas)
  learn/                 Topic list (8 topics) + intro/example/quiz flow
  progress/              Local learning progress (reads localStorage)
  about/                 About, how it works, sources, privacy, safety
components/
  ai/AiResponseCard.tsx  Shared renderer for structured AI responses (Ask + custom scenarios)
  motion/                Reveal, MotionLink — shared Framer Motion primitives used across pages
  scenarios/             ScenarioFlow (examples) + CustomScenario (AI submission form)
lib/
  finance.ts             Savings & loan formulas — the only place numbers are calculated
  content/scenarios.ts   The 4 example scenarios (hand-written, deterministic)
  content/topics.ts      The 8 Learn topics + quizzes (hand-written, deterministic)
  progress.ts            localStorage read/write helpers
  ai/gemini.ts           Shared Gemini-calling helper used by both AI routes
  ai/systemPrompt.ts     System prompt for Ask MoneySense
  ai/scenarioSystemPrompt.ts  System prompt for the custom-scenario feature
  parseAskResponse.ts    Splits an AI's structured markdown response into UI sections
```

## Running locally

```bash
npm install
cp .env.example .env.local   # then add your GEMINI_API_KEY (see below)
npm run dev
```

## Testing the financial calculations

The whole point of "AI explains, code calculates" only holds up if the code is actually
correct — so `lib/finance.test.ts` independently verifies `calculateSavingsPlan` and
`calculateLoanPlan` against hand-worked examples (including the exact numbers used in the
Learn quizzes and the homepage). Run it with:

```bash
npm test
```

Visit `http://localhost:3000`. Without an API key, every page works except Ask MoneySense,
which shows a graceful "temporarily unavailable" state and points users to Scenarios/Learn
instead — the app never crashes for a missing key.

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `GEMINI_API_KEY` | Yes, for Ask MoneySense | Server-side only — never exposed to the browser. **Free** — get one at [aistudio.google.com/apikey](https://aistudio.google.com/apikey), no credit card required. |
| `GEMINI_MODEL` | No | Defaults to `gemini-flash-latest`, a self-updating alias on Google AI Studio's free tier (1,500 requests/day, 10/minute) — comfortably enough for a hackathon demo or small-scale real use. Only set this if you need a specific pinned version instead of Google's current recommended Flash model. |
| `NEXT_PUBLIC_SITE_URL` | No | Your deployed URL, used for social-preview links, `robots.txt`, and `sitemap.xml`. |

## Deployment (Vercel)

1. Push this repo to GitHub (already done if you're reading this on the deploy branch).
2. Import the repo at [vercel.com/new](https://vercel.com/new).
3. Add the `GEMINI_API_KEY` environment variable in the Vercel project settings.
4. Deploy — no other configuration needed.

## Known limitations (be upfront about these when demoing)

- **Ask MoneySense runs on Gemini's free tier**: 10 requests/minute and 1,500/day. Comfortably
  enough for a demo or personal use, but if it's ever hit, the app returns a friendly "receiving
  a lot of questions" message rather than crashing. Raise these limits by enabling billing on
  the same Google Cloud project if this ever needs to scale beyond hobby use.
- **Google occasionally retires free-tier model names** for new API keys — this actually
  happened once during this project's build (`gemini-2.5-flash` was retired for new keys).
  Two layers of defense now exist: the default model is `gemini-flash-latest`, a self-updating
  alias Google keeps pointed at their current recommended Flash model, and `callGemini`
  (`lib/ai/gemini.ts`) automatically retries once against that alias if any requested model
  ever comes back as retired. If it somehow still happens, Vercel's Runtime Logs for `/api/ask`
  will show a clear `404 ... no longer available` error naming the replacement model.
- **Loan calculation is simplified**: it uses a flat-interest model (interest = principal ×
  rate × term), not a bank's exact reducing-balance amortization. This is clearly labelled in
  the UI ("simplified calculation") — it's for financial-literacy purposes, not a loan quote.
- **Progress is per-device, per-browser**: it's stored in `localStorage`, not synced across
  devices or accounts. Clearing browser data resets it. This is an intentional MVP scope
  decision — no accounts/backend needed for a hackathon demo.
- **Quiz and scenario content is fixed**, not AI-generated, so it's identical for every user.
  This trades personalization for reliability during a live demo.
- **Dependency audit**: `next@14.2.35` (latest patched 14.x) still carries a handful of
  `npm audit` advisories inherited from the Next.js 14 line — all in Server Actions,
  Middleware, i18n routing, and custom-server code paths. This app uses none of those
  features (no `middleware.ts`, no Server Actions, no i18n config, no custom server), so
  they don't apply to this app's actual attack surface. A future iteration could move to
  Next.js 16 for a clean audit, but that's a breaking major-version migration (React 19)
  intentionally deferred past the hackathon deadline.

## What's outside the MVP (by design)

Bank integrations, real accounts/auth, investment recommendations, and multilingual support
are explicitly out of scope for this build — see the product concept document for the full
rationale. The goal was a small, working, demonstrable product, not a large set of unfinished
features.
